# Scrum To AI-DLC Transition Map

## Scrum Terms

- Product backlog
- User story
- Sprint planning
- Refinement
- Task breakdown
- Developer implementation
- QA verification
- Sprint review
- Retrospective

## AI-DLC Terms

- Intent backlog
- Intent brief
- Mob elaboration
- Steering point
- Bolt
- Agent loop
- Testing agent validation
- Human validation gate
- Learning log

## Mapping

| Scrum | AI-DLC |
|---|---|
| Product backlog | Intent backlog |
| User story | Intent brief or capability intent |
| Sprint planning | Mob elaboration and steering |
| Refinement | Ongoing intent elaboration |
| Task breakdown | Bolt decomposition |
| Developer implementation | Coding agent execution |
| QA verification | Testing agent + human validation |
| Sprint review | Demonstrable outcome review |
| Retrospective | Learning log and workflow tuning |

## Planning Cycle For Nethra

1. Capture intent
2. Elaboration with humans and AI
3. Decide architecture boundaries
4. Split into bolts
5. Assign agents
6. Validate at checkpoints
7. Publish changes through PRs
8. Record learning for the next cycle

## Steering Questions

- What outcome are we really aiming for?
- What can an agent execute safely as a bolt?
- Where must a human decide or approve?
- What needs an explanation surface?
- What needs a test before it can move on?
