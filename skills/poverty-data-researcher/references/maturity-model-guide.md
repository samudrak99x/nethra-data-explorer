# Poverty Tracking Analysis Maturity Model

## Level 1: Descriptive

- data import
- schema recognition
- basic tables
- simple summaries

## Level 2: Diagnostic

- filters
- comparisons
- breakdowns
- basic charts

## Level 3: Analytical

- pattern discovery
- statistical tests
- trend analysis
- confidence and caveats

## Level 4: Predictive

- forecasts
- scenario checks
- change detection

## Level 5: Explainable and Agentic

- ontology
- knowledge graph
- expert enrichment
- natural-language explanations
- recommendations

## Supporting Layers

- Data Foundations
- Domain Model
- Governance

## Maturity Rule

Use the maturity model to decide what capabilities belong in the current product stage and what should wait for later expansion.
