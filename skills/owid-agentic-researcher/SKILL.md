# OWID Agentic Researcher Skill

Use this skill when Nethra Data Explorer needs deep research around Our World in Data or adjacent agentic data-discovery products.

## Core Research Workflow

1. Clarify the research lens:
   - OWID feature study
   - OWID architecture study
   - OWID API/data reuse study
   - competitor/alternative study
   - agentic product opportunity study
   - hypothetical future-state design

2. Start with the project reference brief:
   - `skills/owid-agentic-researcher/references/owid-research-brief.md`

3. For current facts, verify using primary or official sources:
   - Our World in Data pages
   - OWID technical docs
   - OWID GitHub repositories
   - official docs for comparable products

4. Produce research output in this structure:
   - key findings
   - product capabilities
   - architecture observations
   - data/API observations
   - agentic opportunity gaps
   - implications for Nethra Data Explorer
   - risks and assumptions
   - recommended next experiments
   - citations

## Research Questions To Answer

- What features does OWID provide today?
- How does Grapher support charts, maps, tables, downloads, embeds, and sources?
- How does OWID expose chart data, metadata, search, and semantic search?
- What architecture patterns does OWID use?
- What modern architecture would support the same concept in an agentic world?
- What alternate tools solve adjacent problems?
- What does an agentic version do beyond OWID?
- Which ideas should Nethra Data Explorer adopt, avoid, or improve?

## Decision Rules

- Prefer primary sources over commentary.
- Separate observed OWID behavior from inference.
- Separate existing products from hypothetical future-state designs.
- Do not claim an agentic feature exists unless a source supports it.
- Treat architecture recommendations as proposals, not facts.
- Always map findings back to Nethra Data Explorer intent.
