# AI-DLC Bolt Catalog

## Bolt Definition
A bolt is a small, agent-executable unit of work with a single outcome, clear inputs and outputs, a validation check, and a human steering point when needed.

## Bolt Families
- Import Bolts
- Interface Bolts
- Meaning Bolts
- Knowledge Bolts
- Visualization Bolts
- Pattern Bolts
- Explainability Bolts
- Statistics Bolts
- Conversation Bolts
- Reasoning Bolts
- Narrative Bolts
- Workspace Bolts
- Delivery Bolts

## Bolt Rules
- One outcome per bolt
- One owner agent per bolt
- One validation check per bolt
- Small enough to implement, test, and review quickly
- Must connect back to an intent brief
