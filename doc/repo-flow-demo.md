# Repo Flow Demo

This note exists to prove the end-to-end branch, commit, and pull request flow.

Flow:
1. Create branch
2. Add a file
3. Commit the change
4. Open a pull request
5. Review and merge

Tool split:
- Local git for branch and commit mechanics when available
- GitHub plugin for branch, file, PR, and merge workflows
- GitHub MCP for hosted GitHub context when connector coverage is needed
