# Product Intent Knowledge Base

## Product Name

Working name: Nethra Data Explorer


## Product Summary

Nethra Data Explorer is a dynamic, explainable data intelligence app. It imports datasets, understands schema and ontology, generates the user interface dynamically, discovers patterns, runs statistical analysis, explains findings, and generates reports.


## First Domain

Poverty tracking.


## Primary User

A user who wants to explore social, economic, or development indicators without manually building a custom dashboard for every dataset.


## Product Differentiator

The product is not just a dashboard.

It combines:
- data discovery
- ontology discovery
- dynamic UI generation
- pattern discovery
- statistical modeling
- explainable AI
- natural-language analysis
- report generation


## Product Principles

- Dataset-driven, not page-driven.
- Explainable by default.
- Human-correctable.
- Evidence-backed.
- Testable at each sprint.
- Rule-based first, LLM later.
- No causal claims unless supported.
- Forecasts must show uncertainty.


## Codex Implementation Guidance

When implementing this product, Codex should:
- Preserve explainability.
- Keep modules separate.
- Prefer deterministic analysis before LLM reasoning.
- Add evidence to insights.
- Avoid hiding assumptions.
- Update sprint tracker after meaningful work.
- Keep demos testable.
